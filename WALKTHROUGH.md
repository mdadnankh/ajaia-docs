# Walkthrough video outline (3–5 minutes)

Record unlisted Loom or YouTube. Cover these beats:

1. **Product (20s)** — Ajaia Docs is a scoped Google Docs slice: drafts, import, share, persist. Not a full suite.
2. **Login (20s)** — Two seeded users. Sign in as Alex.
3. **Create + edit (60s)** — New document, rename, bold/italic/underline, heading, list, wait for autosave, refresh to prove persistence.
4. **Import (40s)** — Import a small `.md` file. Point at the UI copy that only `.txt` and `.md` are supported.
5. **Share (60s)** — Share with `jordan@ajaia.dev`. Sign out, sign in as Jordan. Show the doc under Shared with you. Edit as collaborator. Show that Jordan cannot rename or change sharing.
6. **Tradeoffs (40s)** — No realtime, comments, or DOCX. Depth on access + editor instead.
7. **Implementation (30s)** — Next.js App Router, Postgres/Prisma, TipTap HTML, cookie auth, access helpers tested in Vitest.
8. **AI (20s)** — Cursor sped up boilerplate; I kept the permission model and scope cuts.

Keep it under 5 minutes. Speak to the screen, not a slide deck.
